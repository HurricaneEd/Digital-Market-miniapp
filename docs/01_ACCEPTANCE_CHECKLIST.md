## 小程序人工验收步骤

在微信开发者工具中导入 `D:\PycharmProjects\DigRecSys\miniapp`，启动后端后按以下顺序执行：

1. 打开首页，确认搜索栏与微信胶囊对齐，搜索栏和分类 tabs 吸顶。
2. 点击首页分类 tabs，确认商品在首页原地切换；上拉触底后确认继续加载下一页，直至显示“已展示全部商品”。
3. 在首页搜索并清空关键词，确认结果原地更新且分页状态重置。
4. 进入分类页，确认左侧分类切换、右侧商品独立滚动、下拉刷新、触底分页和商品详情跳转。
5. 进入商品详情，确认主图、价格、库存、品牌、分类和动态参数展示。
6. 登录后重新执行商品详情加入购物车，并进入订单列表和订单详情。
7. 使用无效 API 地址或断开网络，确认错误提示、重试和空数据状态。
8. 在没有商品、没有分类、没有订单的账号/环境中确认空状态页面。

以上步骤当前尚未在微信开发者工具或真机中执行，相关用例统一标记为 `NEEDS_MANUAL`。
